DETAILED CHANGELOG

What's improved.

Explore each area to see the fixes, refinements and new groundwork included in the upcoming update.

01 /↗RageTargeting · Accuracy · Stability
16 CHANGES+
  • Improved target selection and candidate ranking.
  • Improved multipoint generation and point refinement.
  • Improved hitchance evaluation and safer force-shot logic.
  • Improved damage / trace pipeline consistency.
  • Added body fallback after failed final verification.
  • Added command-time settings snapshot for HC / MD / force shot.
  • Improved recoil compensation at selected fire time.
  • Improved extrapolation and scoped preparation.
  • Improved autostop and in-air autostop behavior.
  • Improved duck peek preparation and bounded rise logic.
  • Improved shot verification diagnostics.
  • Fixed several fire-time desync edge cases.
  • Fixed candidate replacement inconsistencies.
  • Fixed false miss-cause labeling in several scenarios.
  • Optimized scan order and reduced duplicate point work.
  • Improved Ragebot performance and stability.
02 /◇Anti-AimMovement ownership · Direction · Jitter
06 CHANGES+
  • Improved AA movement ownership and command composition.
  • Improved AA + subtick compatibility groundwork.
  • Improved manual direction handling and jitter stability.
  • Fixed several movement correction inconsistencies.
  • Fixed scope / attack related AA interruptions.
  • Improved shot-angle publishing consistency.
03 /⌁MovementSubtick · Strafer · Movement helpers
09 CHANGES+
  • Improved subtick strafer behavior and diagnostics.
  • Improved quantized movement publication.
  • Improved bhop timing and landing handoff.
  • Improved jumpbug edge publication reliability.
  • Added texturebug and pixel surf helper improvements.
  • Improved movement HUD, keys and velocity graph.
  • Improved native turn planning for movement helpers.
  • Fixed several wall-assist and silent-camera edge cases.
  • Fixed multiple movement ownership conflicts.
04 /◈VisualsMenu · HUD · Feedback
08 CHANGES+
  • Improved menu surface styling and motion.
  • Improved UI navigation, search and preview handling.
  • Improved state persistence and config save behavior.
  • Improved popup transitions and control feedback.
  • Improved HUD message styling and miss feed presentation.
  • Improved weather / fog / resource handling groundwork.
  • Fixed preview publication and display edge cases.
  • Fixed multiple visual state persistence issues.
05 /⌘MiscDiagnostics · Compatibility · Cleanup
06 CHANGES+
  • Improved console + chat logging consistency.
  • Improved config compatibility while keeping new labels.
  • Improved runtime diagnostics and rollback reporting.
  • Updated offsets and current build compatibility.
  • Cleaned several legacy paths and stability issues.
  • Fixed a number of startup and command edge cases.
LOOKING AHEAD

Next on the roadmap.

ONGOING
  • Complete integration of the updated Rage pipeline.
  • Continue porting the most important recovered mechanics.
  • Finish hooking all major systems into the current build.
  • Extend testing on real game scenarios.
  • Optimize performance and remove remaining rough edges.
  • Continue movement / AA / strafe polishing.
  • Continue visuals and misc cleanup.
